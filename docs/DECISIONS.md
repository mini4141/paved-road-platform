# Decisions

One line per decision: date, decision, reason.

- 2026-11-25 | Tooling installed with winget: Go 1.27.4 (go.mod targets 1.25), tflint; kubeconform built via `go install`; Kyverno CLI v1.20.0 from GitHub release. Host Helm is v4.3.2; the Ansible container uses Helm 3.x. | Missing prerequisites per CLAUDE.md §3.
- 2026-11-25 | Ansible runs in a locally built image (`bootstrap/Dockerfile`: python + ansible-core + kubernetes.core + helm 3 + kubectl) via `scripts/ansible.sh`. | Native Windows Ansible is unavailable; no third-party image pinned.
- 2026-11-25 | The portal never writes to Git: it creates ArgoCD `Application` CRs pointing at `charts/golden-service` with user values as inline Helm parameters. | Self-service without Git write credentials (CLAUDE.md §11).
- 2026-11-25 | Add-ons are generated by one ApplicationSet (matrix: git files generator over `gitops/addons/*/addon.json` x cluster generator). The env (`kind`/`eks`) and image registry come from labels/annotations on the in-cluster ArgoCD cluster secret written by Ansible. | Same manifests for kind and EKS; no account ID in Git.
- 2026-11-25 | Locally Traefik is a NodePort (30080) mapped to localhost:8080 by kind extraPortMappings; on EKS it is a LoadBalancer (NLB). | One entry point on both targets.
- 2026-11-25 | Local HTTP port is 8088 (set via KIND_HTTP_PORT in the gitignored .env) instead of 8080. | Port 8080 is held by an unrelated container on this PC; the default stays 8080 in .env.example.
- 2026-11-25 | Kyverno guardrails are `ValidatingPolicy` (policies.kyverno.io/v1, CEL) instead of `ClusterPolicy`. | Kyverno 1.20 no longer accepts legacy `kyverno.io` policy types. The base audits all non-system namespaces; a Kustomize `enforce-copy` overlay denies in namespaces labelled `paved-road/managed=true` (set by the portal).
- 2026-11-25 | Go services build with `golang:1.26` while `go.mod` files stay on the 1.25 line. | Current dependencies require Go 1.26 toolchains.
- 2026-11-25 | The Playwright e2e and the full-stack drills run locally (`E2E=1 scripts/test-all.sh`); CI runs every cloud-free layer except the e2e. | The full platform (~10 GB RAM) does not fit a hosted runner; proof of the e2e is in `proof/`.
- 2026-11-25 | The Grafana admin Secret is generated by the Ansible bootstrap and kept only in the cluster; anonymous Grafana/ArgoCD access is read-only. | Chart-generated random passwords changed on every sync and locked the admin out; no secret is committed.
- 2026-11-25 | Golden services add a 5 s SIGTERM shutdown delay and a Traefik retry middleware. | The first pod-kill drill showed 1.5% errors (requests routed to a terminating pod); after the change it is 0%.
- 2026-11-25 | The ApplicationSet injects the image registry only for the portal via `templatePatch`. | Several add-on charts ship strict value schemas that reject unknown keys.
- 2026-11-25 | EKS version 1.37 (latest standard-support version per aws eks describe-cluster-versions). | Spec asks for the latest supported EKS version.
- 2026-11-25 | (superseded by the 2026-11-26 redeploy) Phase 2 was aborted after terraform apply (Docker Desktop engine stopped mid-deploy) and the stack was destroyed at the user's request; no cloud proof captured. | Never leave cloud resources running.
- 2026-11-26 | On EKS the Traefik LoadBalancer Service stayed pending: this AWS account cannot create load balancers (OperationNotPermitted). Tests, drills and screenshots used `kubectl port-forward` to Traefik. | Account-level restriction only AWS Support can lift; the Service, annotations and manifests are unchanged.
- 2026-11-26 | `scripts/aws-env.sh` regenerates the EKS kubeconfig on every use and passes Windows paths to aws.exe. | A stale kubeconfig from a destroyed cluster pointed at a dead endpoint.
